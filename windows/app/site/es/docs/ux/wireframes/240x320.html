240x320 color (portrait)

30 columns x 26 rows of 8x12 px. UPPERCASE words are drawn in the 2x font (16x24). Example board: any 240x320 radio (DM-32 class if its panel is this size).

Home, dual watch (a call coming in on B)

Two panes of the same size, A over B. The selected pane's tag is filled and its pill says PTT; the pane with the call is green, with the caller and the RX pill on row 2. The selected pane has the arrow under its letter. Under the panes: the state line when there is one, then the last calls, each with its pane's letter. Details: dual-watch.md.

┌──────────────────────────────┐
│ DMR DUAL            ▮▮▮  84% │ DUAL in amber, next to the mode
├──────────────────────────────┤
│ ▓▓▓  3 COUNTY DMR      [PTT] │ tag A filled: the selected channel
│ ▓A▓  TG 3100 USA             │ what PTT talks to
│ ▓▶▓  438.250 MHz TS1 CC1     │ arrow: the selected pane
│      Local repeaters         │ the zone
