Capabilities

What a user can expect a RadioFoundry radio to do, by area, and the build switch and spec behind each. Which radios have a capability, what it costs in flash and what has been checked on each radio are in feature-matrix.md; the switches are in build-config.md. This page names the areas and says nothing about menus, screens or keys: the UI is designed in docs/ux/.
