RadioFoundry

适用于数字电台的开源多模固件：DMR、P25、NXDN 和 FM，采用 MIT 许可证。

安装 用户手册

永久免费。可直接从浏览器安装到您的电台，适用于任何操作系统；无需下载软件。

语音
DMR Tier II 和 III、P25（常规与集群）、NXDN、模拟 FM、航空波段 AM、调频广播、CTCSS/DCS、VOX、DTMF、扫描、VFO、双守候、加密、漫游、单频中继
数据
文本消息、无线区域与信道共享、主叫别名、ARS、位置（LRRP、DMR GPS、T/A、NMEA）、紧急呼叫、呼叫提示、电台检查、ARP、ICMP ping、UDP
网络
USB-DMR IP 网络、网页控制、APRS TNC、MMDVM 热点、USRP、SNMP、TFTP、rigctld 等
工具
网页安装 / 备份 / 电台频率编辑器、兼容 qdmr 的 CPS、崩溃日志、主题、大字体 / 高对比度模式

完整

电台支持的全部功能。

不包含: 无

业余

面向业余无线电，去掉商用功能。

不包含: 基础加密（Motorola / Anytone BP）, Motorola TMS 文本格式, ARS 注册, LRRP 定位, 控制站模式（以网络启动、由电脑应答数据、固定链路）, SNMP v2c 代理与 trap（USB 与空中）

商用

面向商业和公共事业电台，去掉仅供业余使用的功能。

不包含: MMDVM 热点, APRS：AFSK 位置、状态、消息；DMR 位置；KISS TNC
