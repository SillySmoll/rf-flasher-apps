热点模式

在热点模式中，电台作为 DMR 调制解调器，供运行 MMDVMHost、Pi-Star 或类似主机的电脑使用。主机把电台接入 DMR 网络（BrandMeister、TGIF 等）。电台在一个频率上承载附近电台的收发呼叫。电台通过串口使用 MMDVM 调制解调器协议。有 USB 的电台使用 USB 串口；没有 USB 的电台使用编程线（电台参考）。

有些电台的默认镜像不含热点模式。这些电台上工具 > 热点会变暗。电台参考列出这些电台，并说明热点模式在哪里已验证。

你需要什么

  • 一台装有 MMDVMHost 的电脑（Linux、macOS），或树莓派上的 Pi-Star 类镜像。
  • 电台的 USB 线，或没有 USB 的电台的编程线。
  • 不需要编解码器：电台直接转发 DMR 帧，不解码语音。
  • 设置 > 连接 > 允许热点开启（默认）。

设置 MMDVMHost

把 MMDVMHost 的调制解调器指向电台的串口，并作为单工 DMR 热点运行。MMDVM.ini 中重要的部分：

[General]
Duplex=0

[Info]
RXFrequency=438800000
TXFrequency=438800000

[Modem]
Protocol=uart
UARTPort=/dev/ttyACM0
UARTSpeed=115200

[DMR]
Enable=1
ColorCode=1

[DMR Network]
Enable=1
Slot1=0
Slot2=1
  • USB 上，Linux 的端口是 /dev/ttyACM0（或下一个编号），macOS 上是 /dev/cu.usbmodem...。电台的 USB ID 是 1FC9:0094。
  • 收发使用同一频率，且位于电台频段内（电台参考）。
  • 电台只使用时隙 2：请启用网络时隙 2，禁用时隙 1。
  • USB 上忽略波特率。115200 即可。
  • 关闭其他模式（D-Star、YSF、P25、NXDN、POCSAG、FM）。电台会拒绝它们。POCSAG 会被接受但从不发射。

在 Pi-Star 类镜像中，选择电台串口上的 USB MMDVM 调制解调器并使用上述设置。

电台向主机报告自己为“RadioFoundry”、电台型号（例如“RadioFoundry XR-100UV”）以及固件版本。

启动

当主机打开端口并发送第一个 MMDVM 请求时，电台会自行进入热点模式。屏幕切换到热点屏幕。

热点屏幕显示：

  • 状态：STARTING、HOTSPOT、附近电台讲话时的 RX RF、网络呼叫发出时的 TX NET；
  • 频率、色码和功率；
  • 当前或最近一次呼叫，含来源（“RF”或“Net”）、呼叫者和通话组。

OK、6（工具）、3（热点）显示如何启动热点模式。运行期间，该页面有“停止热点”行。

热点模式期间

  • * 在热点屏幕和诊断页面之间切换。
  • PTT 不发射（“热点模式：PTT 关闭”）。
  • 其他任何键显示“热点开启：按 OK 停止”。
  • 若主机请求 CW 标识，电台会以 FM 在热点频率上发送摩尔斯码，然后回到 DMR。摩尔斯为每分钟 20 词、800 Hz。

停止

电台在以下情况离开热点模式并返回其信道：

  • 你按 OK 或长按 返回（“热点已停止”）；
  • 主机关闭端口，或 USB 线被拔出；
  • 主机 20 秒内没有发送任何内容。

要完全阻止电台进入热点模式，请关闭设置 > 连接 > 允许热点。

MMDVM SFR（单频中继）

在 MMDVM SFR 中，热点把在时隙 1 听到的呼叫在同一频率的时隙 2 上重发，同时把呼叫发往网络。直通模式下附近的电台能同时听到。并非每款电台都支持（电台参考）。

主机以双工方式运行并令收发频率相同（Duplex=1，RXFrequency = TXFrequency）即可开启 MMDVM SFR。设为 Duplex=0 或不同频率则关闭。

空中测得的转发时序见电台参考。

独立 SFR

实验性：通过独立 SFR 的呼叫尚不能可靠接通，某些电台之间完全不通。哪些地方失败、在哪款电台、以及变通方法见按电台列出的已知问题。

信道可以是单频中继，或作为其用户的电台，无需主机。请在电台频率编辑器中设置信道的 SFR 角色。信道必须只有一个频率（收发相同）。

角色 电台的行为
中继（Rpt、Rpt Moto） 把入向时隙上听到的每个呼叫在另一时隙上延迟 90 ms 重发。PTT 关闭（“中继信道”）。转发时电台显示接收；发送时红色 LED 点亮。发射被禁止、电量严重不足或扫描/双守候运行时，它保持普通信道，条件解除后继续转发。设置 > 通话与收听 > SFR CW 标识会使其在有通话后每 5 到 30 分钟以摩尔斯码发送呼号
用户（User、ERDM） 在中继台的节拍下于入向时隙通话。播放中继台转发的呼叫副本。设置 > 通话与收听 > SFR 接收还可取用通话者自己的副本：先到的那份，或两份都用，每个损坏帧取自另一份（双路接收）

同一频率上的所有电台必须使用相同的入向时隙。入向时隙为 2 的用户在时隙 1 上收听，因此仍能听到设为入向时隙 1 的用户：两种配置不能共用同一频率。SFR 上没有 CACH：用户跟随中继台的时隙同步。工具 > 单频中继显示信道角色、时隙以及中继台当前的动作。详情见 docs/spec/sfr.md。

两台电台组成双工中继

实验性：两台电台各自接在一台电脑的不同端口上，组成一个全双工中继。一台接收，另一台发射。两者的镜像都需要支持分离双工。功能矩阵显示哪些电台提供该功能。电脑运行 tools/split_duplex_host.py。时隙编号仍在台架上检查。详情见 docs/spec/split-duplex.md。
