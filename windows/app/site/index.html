RadioFoundry

Open-source multi-mode firmware for digital radios: DMR, P25, NXDN and FM. MIT licensed.

Install User Manual

Free forever. Installs on your radio directly from your browser, using any operating system; no software download required.

Voice
DMR Tier II and III, P25 (conventional and trunked), NXDN, Analog FM, Airband AM, Broadcast FM, CTCSS/DCS, VOX, DTMF, Scan, VFO, Dual watch, Privacy, Roaming, Single-Frequency Repeater
Data
Text messages, wireless zone & channel sharing, talker alias, ARS, location (LRRP, DMR GPS, T/A, NMEA), emergency, call alert, radio check, ARP, ICMP ping, UDP
Network
USB-DMR IP Network, Web-based control, APRS TNC, MMDVM Hotspot, USRP, SNMP, TFTP, rigctld, and more
Tools
Web-based install / backup / codeplug editor, qdmr-compatible CPS, crash log, themes, large text / high contrast modes
