Specifications

What the firmware does and what the hardware needs: one page per subsystem, written before the code and kept true to it. Behavior specs are radio-independent. A radio's own facts (pins, chips, quirks, measurements) are on its pages, named by the board id: hardware-<id>.md, codec-<id>.md and, for some, <id>-migration.md. The radios and their chips are in radios.md; which radio has which feature is in feature-matrix.md. Past bugs, by subsystem: gotchas.md. Contributors read docs/dev for process.
