RadioFoundry User Manual

How to install RadioFoundry and use it on the radio. The chapters describe what RadioFoundry does on every radio. The Radio reference lists what differs from radio to radio: the keys, power levels, battery, power switch and display, and what has been checked on each. Each release also carries this manual as a PDF, built from these files (tools/build_manual.sh, in file name order).

Start on the web site, radiofoundry.org: the web installer installs, updates, backs up and restores a radio, and the Codeplug Editor edits channels, zones and contacts. Both run in a Chromium browser. The chapters below name the command line tools as alternatives.

Reading order

Get started

  1. Introduction: what RadioFoundry is, project status, conventions
  2. Installing: the web installer first, then the advanced rfoundry command line; updating, backups, going back
  3. First boot: built-in channels, the first checks
  4. Programming the radio: the Codeplug Editor (P25 and NXDN channels, trunked systems), qdmr, RadioID contacts

Use the radio

  1. Keys and navigation: the five key rules, Find, temporary changes, key lock
  2. The Home screen: what each region shows, receiving, transmitting
  3. Channels, zones and the VFO: P25, P25 trunked and NXDN channels too
  4. FM: squelch, monitor, tones, bandwidth, VOX, touch tones
  5. DMR: talk targets, replying, Recent, contacts, timeslot and color code, privacy, roaming, trunked systems
  6. Messages, call alert and radio check
  7. Emergency
  8. Scan and dual watch
  9. APRS: positions on FM and over DMR, beacons, KISS and iGate with a computer
  10. Hotspot mode: MMDVMHost and Pi-Star, SFR, two radios as a duplex repeater
  11. USB network mode: IP over DMR, the status page, rig control, KISS, TFTP, SNMP, control station
  12. Battery and power

Reference

  1. Settings: every setting, its default and status
  2. Troubleshooting
  3. FAQ
  4. Glossary
  5. Radio reference: keys, power levels, battery, power switch, display, install values, programming and status of each radio

Moving from the stock firmware

These chapters are for a radio that still runs the manufacturer's firmware and has a codeplug worth keeping. One program installs RadioFoundry and carries the codeplug over. Without a chapter, install with the web installer and open its backup in the Codeplug Editor (Installing).

The Radio reference links the chapter from the radio's "Installing" section.
