安装

在电台上安装 RadioFoundry、更新、备份与恢复，推荐使用项目网站 radiofoundry.org 上的网页安装器。它运行在基于 Chromium 的浏览器（Chrome、Edge）中，无需安装任何东西。你载入其中的文件不会离开你的电脑。这里的任何操作都不会改动电台的校准。

命令行工具 rfoundry 可在终端中完成同样的工作。它是进阶选项：用于脚本、无法与电台通信的浏览器，或本地构建（进阶：命令行 rfoundry）。

各机型之间的差异（原厂固件文件、进入引导程序的按键、安装路径）见电台参考中你的电台的“安装”一节。仍运行厂商原厂固件、且有迁移章节的电台，见从原厂固件迁移。

你需要什么

项目 来源
一台装有 Windows、macOS 或 Linux 的电脑，或一台 Android 手机 / 平板 Android：Chrome，以及用于线缆的 USB OTG 转接头（常见问题）
一个基于 Chromium 的浏览器 用于网页安装器
你的电台的原厂固件文件 厂商提供的文件，版本需被安装器识别。你的电台的“安装”一节会说明文件名和获取位置
电台的 USB 线或编程线 随电台附带的线缆

发行版固件包含除 AMBE 编解码器之外的一切。安装器会保留电台中已有的编解码器，或从你电脑上的原厂固件文件中取出并写入电台。原厂文件还为安装器提供电台引导程序所需的密钥。一旦电台运行 RadioFoundry，安装器就改为从电台读取密钥。文件都用 SHA-256 校验，未知文件会被拒绝。

刷写前，先用你现在的程序（厂商 CPS 或 qdmr）备份电台当前的电台频率。RadioFoundry 使用的电台频率布局与原厂固件不同。以后若要回到原厂固件，需要这份备份。网页安装器自带的备份（见下文）也会包含它。

用网页安装器安装

打开网页安装器，选择安装，然后按步骤操作（已经运行 RadioFoundry 的电台：更新 RadioFoundry）：

  1. 电台。 选择你的电台。

  2. 构建。 选择完整（电台支持的全部功能）、业余、商用，或用自定义逐个挑选功能。电台不支持的功能会被标出。自定义构建在你继续时生成，用时不到一分钟。当浏览器请求某种电台能显示、但构建未包含的语言时，页面会提示将其加入（电台上的 设置 > 显示 > 语言，见设置）。电台语言选择电台启动时使用的语言；构建包含该语言时，预设为页面语言。选择构建未包含的语言会把它加入构建。之后可在电台上更改。构建对电台来说过大时，会说明超出多少：在自定义中关掉一些功能，或选择更小的构建，然后重新构建。

  3. 当前固件。 说明电台现在运行什么：

    选项 何时使用
    RadioFoundry 连接电台并开机。安装器会读取已安装的版本。
    原厂固件 出厂时安装的固件。
    其他开源固件 另一个开源固件项目，例如 OpenGD77 系列。
    其他 / 不确定 任何其他固件，或者你不知道电台运行什么。

    安装器只在需要编解码器或密钥时才要求原厂固件文件。如果你选择 RadioFoundry，而电台运行的是 OpenGD77 系列固件，安装器会说明这一点，并改为提供其他开源固件。没有调试链路的 RadioFoundry 构建也会给出同样的回答。

  4. 备份。 安装器会在你的电脑上保存一个备份文件（.zip）：固件、信道与设置，以及校准。请保留它。若无法先读取原厂固件，安装器会在安装后立即备份电台，先于其他任何改动。

    通过编程线安装的电台，线缆较慢，因此安装器会显示每部分所需时间。程序存储器是必需的，除非你改用原厂文件（见下文）。所有信道和设置是可选项，默认关闭：安装器从不改动它们，而整个数据存储器可能需要许多分钟。如果你有电台的原厂固件文件，改用原厂文件可在读取前或读取过程中跳过固件备份。安装器随后只读取编解码器区域，并在下一步从文件取用编解码器。电台中的固件不会被备份，但原厂文件可以恢复原厂固件。

    没有固件备份或原厂文件时，安装器没有编解码器可写入电台。 如果你跳过固件备份且未选择受支持的原厂文件，唯一的选择是不装编解码器安装。安装器会在“安装”按钮上方警告：此次安装不包含 DMR 语音编解码器：模拟 FM 可用，但在你使用受支持的厂商固件文件重新安装 RadioFoundry 之前，DMR 语音不可用。再次安装会保留你的信道和设置。按下安装时，对话框会再问一次：返回并添加编解码器回到选择文件的步骤，仍然安装则不装 DMR 语音继续。

    备份发现某个固件版本的编解码器尚未被 RadioFoundry 映射时，也会出现同样的选择。备份本身仍然完整；编解码器步骤会改为要求受支持的原厂固件文件。

  5. 安装。 在提示时把电台置于其引导程序（你电台的按键）。安装器写入变更的部分并重启电台。在提示安装完成之前，不要拔下电台。

  6. 校验。 安装器读取电台报告的内容：它写入的版本，以及编解码器就位时的“DMR 语音已就绪”。

  7. 信道。 如果电台仍保留原厂固件的电台频率，安装器会将其转换为 RadioFoundry 布局并写入电台，然后读回并显示迁移了多少信道、区域和联系人。备份包含原厂电台频率后，这一步会自动运行。若你跳过了备份，安装器会先询问：在某些电台上，转换后的电台频率会替换原始字节。在将原厂电台频率与 RadioFoundry 的分开保存的电台上，无论有无备份都会运行，只在替换电台上已有的 RadioFoundry 电台频率之前询问。更新 RadioFoundry 会跳过这一步。如果安装器无法读取、转换或写入原厂电台频率，它会说明原因，电台将在没有信道的情况下启动：按备份与恢复所述转换备份。

在 Windows 上，引导程序需要安装一次驱动（Windows：引导程序驱动）。

然后继续首次启动。

从其他开源固件转来

在运行 OpenGD77 系列固件的电台上，安装器可以在安装前通过该固件备份整个电台，并从备份中取得更新密钥和语音编解码器。这样就不需要原厂固件文件。安装器只在可行的电台上提供此选项；其他电台仍照常需要原厂固件文件。

  1. 在当前固件中选择其他开源固件，然后在电台已连接并开机时选择检查电台。选择 RadioFoundry 也能发现其他固件。安装器会报告其版本。
  2. 选择备份并读取。备份约需一分半钟，只读取，不会改动电台。请保留保存的文件。
  3. 安装器会说明是否找到了更新密钥和编解码器。若两者都找到，继续即可：编解码器步骤使用电台中的编解码器。若都没找到或只找到一个，请在编解码器步骤选择你的原厂固件文件。跳过备份或电台报告为其他型号时也是如此：编解码器步骤会要求原厂文件。其他开源固件的安装器可能已把它选定的某个电台固件中的编解码器放了进去；备份会发现它，电台参考中你的电台一节会说明哪些文件算数。
  4. 照常通过引导程序安装。

如果备份过程中电台停止响应，请关机再开机，然后选择继续读取：备份会从停止处继续。保存已读取内容会保留目前已读取的部分。

若要回退，选择恢复并载入该备份，然后选择之前的开源固件。固件会被写回；信道和设置不会。若缺少它们，请用该固件自带的编程软件写入。

此路径尚未在真实电台上测试过。请把原厂固件文件放在手边。

更新 RadioFoundry

在 RadioFoundry 正常运行时启动电台，然后在网页安装器中选择更新：

  1. 连接电台并点击连接。端口列表会同时显示电台的 USB 口和编程线。
  2. 安装器显示电台、已安装版本、新版本以及电台的构建（完整、业余、商用或自定义）。更新会安装新发行版的同一构建。
    • 编辑构建会打开构建步骤，在更新前更改功能。
    • 预设构建会列出新发行版为其增加的功能。
    • 自定义构建会列出自其生成以来新增的功能。更新前为每一项选择开或关。
    • 版本过旧、无法报告构建的固件会进入构建步骤，从最接近的匹配开始。
    • 电台保持其启动语言。如果之前的一次更新可能误改了它，安装程序会询问是保留该语言还是以英语启动。
  3. 先保存备份是可选项，默认关闭。更新会保留信道、设置、校准和编解码器。
  4. 点击更新。安装器生成镜像、写入并核对版本。

电台会从 RadioFoundry 直接进入加载器：无需按键组合，也无需原厂文件。电台频率和设置都会保留：它们位于更新从不触碰的闪存中。对运行 RadioFoundry 的电台，安装仍然可用，只是会问所有问题。

备份与恢复

备份会保存一个文件，包含电台的固件、编解码器、信道和设置。恢复用该文件写回整个电台、仅固件，或仅信道和设置；也可以从你的原厂固件文件把电台恢复为原厂固件。厂商文件只要适用于你的电台即可，不限于安装器为编解码器所需的那个版本。即使在固件损坏时，也可从更新模式恢复。

备份会像安装一样询问电台当前运行什么。RadioFoundry 通过调试链路读取。其他开源固件通过该固件读取，仅限安装器支持的电台。处于原厂固件的电台不在此处备份：请选择“安装”，它会在安装后立即备份。

每款电台都会列出所有备份选项及其耗时：程序存储器、出厂校准，以及所有信道和设置。仅校准（或出厂校准）只读取出厂校准。在程序存储器中保存校准副本的电台，该选项名为程序存储器与校准。信道和设置位于 NAND 存储器的电台，所有信道和设置会读取整个 NAND，可能需要数分钟。

没有程序存储器，使用这些工具无法把备份恢复到电台最初的原厂固件。恢复只写回程序存储器；备份中的校准和数据存储器仅作记录保留。选择此类备份时，恢复会说明这一点，并提供选择固件文件：改为选择适用于你电台的厂商固件文件，版本需受安装器支持。电台完整的程序存储器转储同样可用，即使其固件版本尚未被映射：恢复会原样写回，绝不触碰引导程序。在版本被映射之前，安装无法使用该转储的编解码器，因此安装器会提议把转储发送给 RadioFoundry 团队进行映射，并改为要求受支持的厂商固件文件。

解压后又重新打包的备份（macOS 会自动解压下载文件）仍然可以恢复。备份就是那个 .zip 文件本身（文件名是电台型号、_Backup_ 和日期），而不是其中的某个文件。选择非备份文件时，恢复会说明它是什么，以及应选择什么。原厂固件文件则继续进入原厂固件恢复流程，前提是电台无需备份即可支持。

如果备份包含原厂固件的电台频率，请在电台频率编辑器中打开该文件。它会将信道、区域和联系人转换为 RadioFoundry 布局。

Windows：引导程序驱动

Windows 没有适用于通过 USB 刷写的电台 USB 引导程序的驱动，因此在你安装驱动之前，网页安装器和 rfoundry 都无法打开它。每台电脑只需用 Zadig 做一次：

  1. 从 zadig.akeo.ie 下载 Zadig 并运行。无需安装。
  2. 把电台置于引导程序（按键见其电台参考一节）并插上。
  3. 在 Zadig 列表中选择 Digital Radio in USB mode。USB ID 框会显示 0483 DF11。若未列出，选择 Options > List All Devices。
  4. 选择 WinUSB 作为驱动（绿色箭头右侧），点击 Install Driver（或 Replace Driver）。等待 Zadig 提示成功。
  5. 拔下电台，重新置于引导程序并再次连接。

只有引导程序需要这个驱动。电台运行 RadioFoundry 后，其串口无需驱动即可工作。

使用相同 USB ID 的厂商工具（厂商升级工具或 CPS）需要装回它们自己的驱动。请在设备管理器中卸载该设备，勾选删除此设备的驱动程序软件，然后重新插入。

用安装包从命令行安装

网页安装器无法安装时，会提供手动安装包：一个 zip，包含在这台电脑的终端中用 rfoundry 安装你所选固件所需的一切。照常选择和构建固件；安装包会取用该固件。

进阶：命令行 rfoundry

每个发行版都附带 rfoundry，每个系统一个文件，名为 rfoundry-<version>-<system>。也可以用 pipx install 安装（tools/rfoundry/README.md）。

系统 一次性设置
Windows 安装引导程序的驱动（见上）。Windows 可能会警告 rfoundry 文件未签名
macOS 在终端中执行：xattr -d com.apple.quarantine rfoundry-* 和 chmod +x rfoundry-*（文件未签名）
Linux chmod +x rfoundry-*。若 rfoundry 提示拒绝访问，它会打印需要添加的 udev 规则。电台运行 RadioFoundry 后，要访问其串口（rfoundry probe、更新），请加入 dialout 组：sudo usermod -aG dialout $USER，然后重新登录

示例中称其为 rfoundry，原厂文件为 STOCK.bin。若不想每次都传入原厂文件，可让 rfoundry 保存密钥：

rfoundry key --stock STOCK.bin --save

刷写

rfoundry flash --release latest --stock STOCK.bin

有些电台存在一个镜像无法覆盖的硬件版本，例如 UHF 和 VHF 板。它们每个版本一个镜像。rfoundry 会依据已运行 RadioFoundry 的电台报告来选择，否则询问，或接受 --option BAND=vhf。你的电台一节会列出其版本。

rfoundry 下载最新发行版、校验、决定编解码器（见下），并打印计划：将擦写哪些闪存扇区，哪些保持不动。加上 --dry-run 可只看计划而不触碰电台。然后它会要求你把电台置于引导程序：

  1. 关闭电台。
  2. 把线缆连接到电台和电脑。
  3. 按住电台的引导程序按键并开机。屏幕保持黑屏。
  4. 松开按键。

rfoundry 找到引导程序，再询问一次，然后写入。完成后电台重启进入 RadioFoundry，rfoundry 会核对电台报告的内容。

保留编解码器，或写入它

电台运行 rfoundry 的做法
RadioFoundry，且 DMR 语音正常 保留编解码器：只写 RadioFoundry 自己的扇区。它会在你切换到引导程序之前通过 USB 询问正在运行的电台（或先运行 rfoundry probe）
其他任何情况，或不确定 写入编解码器：优先使用它上次运行 RadioFoundry 时从该电台保存的副本，否则使用原厂文件（--stock）

原厂固件把编解码器放在 RadioFoundry 自己固件所在的位置，因此刚从原厂状态来的电台需要原厂文件一次。之后，rfoundry 会在你电脑上保存一份编解码器副本。

如果 rfoundry 保留了实际不在电台中的编解码器，也不会出问题：RadioFoundry 在使用前会检查编解码器。FM 可用，DMR 呼叫会显示“无编解码器：语音关闭”。用 --stock 重新刷写即可修复。

更新

rfoundry flash --release latest

自行构建

开发者用 make BOARD=<board> 构建，并用 rfoundry flash build/<board>/rfoundry_<board>.bin --board <board> 刷写（编解码器选择相同）。把原厂文件放进 codecs/ 后，构建还会生成 rfoundry_<board>_codec.bin，其中带有编解码器：rfoundry flash build/<board>/rfoundry_<board>_codec.bin 可在不带 --board 的情况下刷写，只有引导程序密钥还需要 --stock。见构建。

没有编解码器（“无编解码器：语音关闭”）

屏幕上显示 DMR 呼叫但没有声音：电台没有可用的编解码器。再次运行安装器并给它原厂固件文件，或在终端中执行：

rfoundry flash --release latest --codec merge --stock STOCK.bin

安装器无法使用某个文件时

如果固件文件无法使用，安装器会说明发现的问题和该怎么做：

提示 处理
此文件属于另一款电台 选择你电台的文件，或打开该文件所属电台的安装器
这不是厂商固件文件 选择厂商原始文件。其他开源固件项目的构建不可用
此文件不适用于（你的电台） 它属于其他型号，或被修改过的构建。请选择适用于你电台的厂商文件
尚不支持此版本的编解码器 选择其下方列出的受支持文件之一，或发送该文件以便添加此版本
文件已损坏或不完整 重新下载
电台编程工具无法使用此文件 文件本身没有问题。安装器会报告故障，或说明如何报告；你也可以发送该文件以协助排查

尚未支持的版本仍可能提供引导程序密钥；提示中会说明。你也可以在没有可用文件的情况下继续：安装器会保留电台中已有的编解码器，并在写入前说明 DMR 语音依赖它。

技术细节会显示确切消息。仅对厂商固件文件提供发送选项，且只在你点击时发送。自动错误报告会包含文件名（名称、大小和校验和），绝不包含内容。

出问题时

引导程序位于安装器从不擦除的闪存区域，因此你总能重新开始：把电台置于引导程序并重新安装。刷写后电台一直黑屏时，也照此处理。网页安装器的帮助页会逐步说明更新模式。另见故障排查。

报告问题位于每次失败信息下方、每个步骤下方的按钮栏中以及校验步骤上。页面看起来卡住却没有显示错误时，请在重新加载之前使用它：重新加载会丢失日志。它会发送安装器的判断及最后几步。你可以附加消息、用于回复的邮箱，以及它列出的文件（原厂固件文件、备份、从电台读出的固件）。备份包含你的信道、联系人和电台校准：取消勾选即可不包含。附件和你的邮箱地址会在 90 天内删除。

电台停留在更新模式： 备份或安装因拔线中断，或中途关闭页面，可能让电台停留在加载器（更新模式），此时电源开关可能无效。在安装器首页选择电台停留在更新模式并选择电台。对于通过编程线编程的电台，也请选择线缆，安装器会把它重启到正常模式；其他电台则由页面说明如何手动重启。你在做其他任务时连接，而加载器已在运行，连接步骤会在继续旁提供重启电台。如果加载器完全无响应，请关闭再打开电台；若电源开关无效，取出电池几秒。在备份之后，重启电台会在完成页面结束任务，并提供“安装”或“完成”（电台运行 RadioFoundry 时还有“更新”）。

编程线： 使用 CH340 芯片的线缆在备份和安装时可能不可靠。若失败，请改用 FTDI、CP210x 或 PL2303 芯片的线缆。安装器检测到 CH340 线缆时会警告。

线缆无法准备电台时： 通过编程线安装的电台会先在内存中得到一个小型加载器。电台开机时只等待约 1/20 秒来接收安装器的应答，而某些线缆和 USB 集线器比这更慢。因此安装器会在电台启动期间持续发送应答（这原本是单独的慢速线缆模式，现在始终开启）。关闭电台，选择电台已关闭，然后开机。已运行 RadioFoundry 的电台会跳过该步骤。

如果加载失败（“准备电台失败”）、电台改为正常启动，或始终无应答，安装器会提供使用厂商更新模式：即电台自带的更新模式，通过在开机时按住按键进入（电台参考中你电台的“安装”一节）。这种方式无法从电台读取任何内容，因此不会备份，语音编解码器来自文件：原厂固件文件，或在安装器没有该电台原厂文件时使用电台的程序存储器备份。故障排查也提供同一路径（“在厂商更新模式中重新安装”），恢复也会使用它。

回到原厂固件

  1. 把电台置于引导程序。
  2. 在网页安装器中选择恢复，载入你的备份并选择原厂固件，同时提供原厂固件文件（适用于你电台的任意版本）。如果安装器在首次安装前备份了原厂固件（见你电台的一节），载入该备份；没有备份时，载入厂商固件文件。或者运行厂商的固件升级工具并载入原厂文件。
  3. 用厂商 CPS 写入你的电台频率备份。原厂固件无法读取 RadioFoundry 使用过的电台频率。

电台参考中你的电台一节会说明适用哪种方式。
