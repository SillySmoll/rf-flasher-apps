RadioFoundry 用户手册

如何在电台上安装并使用 RadioFoundry。各章描述 RadioFoundry 在每款电台上的行为。电台参考 列出各机型之间的差异：按键、功率档位、电池、电源开关和显示屏，以及每款电台已经验证过的项目。每个发行版还附带由这些文件生成的 PDF 手册（tools/build_manual.sh，按文件名顺序）。

从网站 radiofoundry.org 开始：网页安装器可以安装、更新、备份和恢复电台，电台频率编辑器可以编辑信道、区域和联系人。两者都在 Chromium 浏览器中运行。下文各章把命令行工具作为替代方式。

阅读顺序

入门

  1. 简介：RadioFoundry 是什么、项目状态、约定
  2. 安装：先讲网页安装器，再讲进阶的 rfoundry 命令行；更新、备份、回退
  3. 首次启动：内置信道、最初的几项检查
  4. 为电台编程：电台频率编辑器、qdmr、RadioID 联系人

使用电台

  1. 按键与导航：五条按键规则、查找、临时更改、按键锁
  2. 主屏幕：每个区域显示什么、接收、发射
  3. 信道、区域与 VFO
  4. FM：静噪、监听、亚音、带宽、VOX、双音多频
  5. DMR：通话目标、回复、最近呼叫、联系人、时隙与色码、加密、漫游、集群系统
  6. 消息、呼叫提示与电台检查
  7. 紧急
  8. 扫描与双守候
  9. APRS：FM 与 DMR 上的位置、信标、与电脑配合的 KISS 和 iGate
  10. 热点模式：MMDVMHost 与 Pi-Star、SFR、两台电台组成双工中继
  11. USB 网络模式：DMR 承载 IP、状态页、rig 控制、KISS、TFTP、SNMP、控制站
  12. 电池与供电

参考

  1. 设置：每一项设置、默认值和状态
  2. 故障排查
  3. 常见问题
  4. 术语表
  5. 电台参考：每款电台的按键、功率档位、电池、电源开关、显示屏、安装参数、编程方式和状态

从原厂固件迁移

这些章节适用于仍运行厂商固件、且电台频率值得保留的电台。一个程序即可安装 RadioFoundry 并迁移电台频率。没有对应章节时，用网页安装器安装，并在电台频率编辑器中打开它的备份（安装）。

电台参考 会从各电台的“安装”一节链接到对应章节。
